# Benchmarks

Generated by `make bench-report` from [`results.json`](results.json); do not edit by hand. Regenerate the results with `make bench`. Methodology: `docs/design.md` §8.5 and `packages/bench/`.

Ran on Darwin arm64, Python 3.13.5, OR-Tools 9.15.6755. LNS ran as production runs it: greedy, then search, inside a 1 s wall-clock budget (at most 20,000 iterations). The exact model is set partitioning on CP-SAT, given LNS's answer as a hint and 300 s to prove it, for every instance up to n = 50.

Every instance is synthetic (`generate_instance`, haversine travel times, no flexible drivers). These are not measurements of real events.
